# Compile Python Bindings with Pybind11 (MacOS Only)

Make sure you have 'pybind11' and a C++ compiler installed on your system. Also, make sure you have FFTW3 installed (via brew)

    chmod +x build.sh                      
    ./build.sh


This will generate the shared library file `pybind11_example.so` in the `pybind` directory.
