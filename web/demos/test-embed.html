Hosting
Self-hosting setup
  1. Click ⬇ Download Files above to get frft-embeds.zip.
  2. Extract the ZIP — you will see a projects/ folder. Move it into your site's assets/ folder so the path becomes assets/projects/frft/….
  3. Copy the embed code snippet for each widget below and paste it into your page.
